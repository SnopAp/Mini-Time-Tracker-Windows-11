# Mini Time Tracker для Windows 11 (C# / WPF / .NET 10 LTS)

Минималистичный персональный трекер времени, выполненный в виде плавающего компактного виджета для Windows 11 x64.

## Основные возможности

1. **Точный таймер**: Отображение времени в формате `HH:mm:ss`, расчёт длительности ведётся строго по разнице временных меток UTC (`DateTimeOffset.UtcNow`), исключая дрейф секунд.
2. **Управление сессиями**: Запуск и остановка сессий одной кнопкой. Запрет одновременного запуска нескольких сессий.
3. **Активности**: Активность «Работа» по умолчанию, возможность создавать собственные активности с цветовым маркером.
4. **Безопасное JSON-хранилище**:
   - Файл данных: `%LOCALAPPDATA%\MiniTimeTracker\data.json`
   - Атомарная запись через временный файл (`File.Replace`), исключающая порчу данных при внезапном выключении.
   - Защита от затирания повреждённого файла: при ошибке синтаксиса создаётся резервная копия `data.corrupt.{timestamp}.json`, а пользователю выводится предупреждение.
   - Запись только при изменении состояния (старт/стоп/настройки), диск не нагружается ежесекундной записью.
5. **Интерфейс виджета Windows 11**:
   - Окно без рамок (`WindowStyle=None`, `AllowsTransparency=True`).
   - Полупрозрачный фон с акриловым эффектом и скруглёнными углами (Fluent Design).
   - Перемещение мышью в любую область экрана (`DragMove`).
   - Закрепление поверх всех окон (`Topmost`).
   - Всплывающие кнопки управления при наведении курсора (Hover panel).
   - **Скрытие у края экрана (Этап 4)**: виджет автоматически сворачивается за край монитора, оставляя аккуратную выступающую полоску-язычок, и мгновенно раскрывается при приближении курсора.
6. **История сессий**: Просмотр списка завершённых сессий (активность, дата/время начала и окончания, длительность).

## Требования для сборки

- Windows 10/11 x64;
- .NET 10 SDK (или .NET 8 / 9 SDK при смене TargetFramework в `.csproj`).

## Команды сборки и запуска

### 1. Быстрый запуск в режиме разработки:
```bash
dotnet run --project MiniTimeTracker.csproj
```

### 2. Сборка автономного исполняемого файла (Self-Contained Single File):
```bash
dotnet publish MiniTimeTracker.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ./publish
```
После завершения в папке `publish/` появится один файл `MiniTimeTracker.exe` (~65-75 МБ со всеми системными библиотеками WPF и среды исполнения .NET 10). Его можно запускать на любой Windows 11 x64 без предустановленного .NET Runtime.
